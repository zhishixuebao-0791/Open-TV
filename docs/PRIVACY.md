# 隐私与无源发布原则

## 当前公开内容

本仓库包含去源应用源码、构建入口、单元测试、说明文档及来源声明。不会上传维护者的直播源表、主备订阅地址、访问令牌、私人日志、设备截图、偏好备份、私钥、构建缓存或历史 APK。

格式示例只使用 `.invalid` 保留域名，不是可用直播源。仓库不会提供实际直播源、源表托管或找源服务。

## 公开无源版本

无源版与维护者私人使用的应用分开：

- 不打包内置频道表、旧 JSON / DAT 数据或私人订阅默认值。
- 主、备用订阅初始为空；清空后不会恢复隐藏默认地址。
- 没有主订阅时不发起订阅获取；只填备用地址不会自动建立主订阅。
- 移除 Bugly 依赖、上报初始化和原项目的统计账号标识。
- 使用独立 applicationId，避免覆盖私人版安装或直接迁移其订阅偏好。
- 关闭应用备份，并在 Android 备份和设备迁移规则中排除应用偏好及数据目录。

上述处理已进入公开源码，不代表完成了各厂商系统或第三方 SDK 的全部隐私审计。

## 配置后仍需了解的行为

订阅检查、播放和网页加载会向用户配置的服务器及其引用的站点发出请求，对方可能看到设备 IP、访问路径和相关请求信息。网页和第三方 SDK 还可能有自己的外部请求；移除 Bugly 不代表完全消除了所有第三方网络行为。

频道表、有效缓存及播放偏好需要存放在应用本机数据目录。应用不会把你的列表上传到本项目仓库，但卸载、清除数据、设备备份策略或第三方服务条款仍应按实际环境理解。

请不要在公开 Issues 或 PR 中粘贴带账号、令牌或鉴权参数的 URL。排查问题时优先使用自行生成、无个人信息的最小测试样例。
