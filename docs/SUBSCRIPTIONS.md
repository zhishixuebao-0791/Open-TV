# 订阅配置与频道表格式

> 当前仓库仅提供文档，应用源码和安装包待上游授权确认。以下描述对应已准备的本地去源候选版，不是当前可下载软件的使用承诺。

**本项目及维护者不提供直播源表、默认订阅或可用节目地址。** 你需要自行取得允许你使用的内容和订阅服务。

## 两种地址分别是什么

| 配置 | 含义 | 留空行为 |
| --- | --- | --- |
| 订阅地址 | 返回一份频道 M3U 文本的 HTTP(S) URL | 不发起订阅请求，显示未配置状态 |
| 备用地址 | 主订阅网络请求或内容校验失败时尝试的另一份 M3U 文本 URL | 禁用备用订阅，不恢复默认值 |
| 频道线路 | M3U 中每个 `#EXTINF` 后面的播放 URL | 没有有效地址的条目不会形成可用频道 |

备用订阅只有在主订阅已经配置时参与检查。它的内容应该是同一套频道目录的备用副本；不要把两个互不相关的目录当作自动合并订阅。

同一个频道的多线路，需要在**一份频道表**里重复写同组同名的 `#EXTINF`，分别跟随不同播放地址。

## 在应用内填写

1. 打开“频道设置 → 应用设置”。遥控器可按菜单键或长按确认键打开频道设置。
2. 进入“订阅地址”，填写完整的 `https://` 或 `http://` URL 并保存。
3. 按需要配置“备用地址”，或者保持空白。
4. 选择“刷新频道列表”，查看设置底部的检查结果。

两处输入框初始为空，也没有“留空使用默认订阅”的提示。清空并保存主订阅后，应用不会重新填入维护者地址，不会转用隐藏内置表；清空备用地址后保持禁用。

## 订阅服务器返回什么

- UTF-8 文本，可带 UTF-8 BOM；建议第一行是 `#EXTM3U`。
- HTTP 成功响应的正文必须是频道列表，不是网页、登录页、分享页或 GitHub 文件浏览页。
- HTTP(S) 重定向可以使用，最终内容仍应为上述文本。服务器可选返回 `ETag` 并处理 `If-None-Match` / `304 Not Modified`。
- 响应体最大 4 MiB；超过上限或没有有效频道的结果不会替换有效缓存。
- 推荐 HTTPS。HTTP 明文可能泄露路径、查询参数及访问内容；不要把带令牌的订阅放到公开仓库、日志或问题反馈中。
- 若需要自建服务，只发布你拥有适当授权的频道表及内容；把文件放上服务器不会自动获得传播权。

订阅 URL 的文件扩展名不是判断依据；URL 必须返回可解析的频道表。**频道目录 M3U 与 HLS 媒体清单不是一回事**：不要把只有媒体分片的 HLS `index.m3u8` 直接填写为频道目录订阅。

## 最小示例

以下是格式说明，使用保留的 `.invalid` 域名，不是可播放直播源：

```m3u
#EXTM3U
#EXTINF:-1 group-title="自有内容",示例频道 A
https://media.example.invalid/a/index.m3u8
#EXTINF:-1 group-title="自有内容",示例频道 A
https://media.example.invalid/a/backup.m3u8
#EXTINF:-1 group-title="测试内容",示例频道 B
https://media.example.invalid/b/video.mp4
```

该示例会形成两个频道：A 有两条线路，B 有一条线路。使用时必须把示例 URL 换成你有权访问的真实地址。

## 解析规则

| 字段或形式 | 当前实现 |
| --- | --- |
| `#EXTM3U` | 在线订阅校验需要此头部标记，且至少有一个有效频道 |
| `#EXTINF:-1 ...,频道名` | 最后一个英文逗号后的文本作为频道名称；不要在名称里再放英文逗号 |
| `group-title="分组名"` | 使用双引号；缺省或空值归入“默认”组 |
| 下一行 HTTP(S) URL | 必须是完整绝对地址，且有主机名；不接受相对路径、`file:`、`rtsp:` 或 UDP 地址 |
| 同组同名多行条目 | 规范化频道名称后合并为多线路，完全相同的 URL 去重 |
| 不同分组 | 频道名称相同也分别保留 |
| `tvg-id`、`tvg-logo`、EPG 参数 | 当前解析器不消费这些字段；出现不等于支持节目单或图标 |
| `#EXTVLCOPT`、附加 Cookie / Header 指令 | 不作为自定义请求头执行；不要依赖此类指令播放 |
| TXT、TVBox JSON、XSPF、Xtream API | 此订阅入口没有实现这些格式的导入 |

频道名称会处理空白、部分分隔符及常见画质后缀。因此，为避免误合并，内容不同的频道应使用清楚可区分的名称或分组；不要只用 `HD` 等后缀区分两套不同节目。

频道 URL 可以指向播放器支持的 HTTP(S) 媒体或网页。容器格式、编码、DRM、登录权限和源站策略仍可能影响播放；符合 M3U 语法不保证对应媒体可播。

## 更新和失败时的行为

前台通常每 30 分钟检查一次，启动、恢复前台或手动刷新也可能触发检查。失败后会调整下一次重试时间，避免快速重复请求。

主订阅失败时尝试已配置的备用订阅；两者都失败时，若有同一主订阅对应的上次有效缓存则保留它，没有缓存则显示空频道状态。**不回退到项目维护者的直播源。** 有效新目录在正常播放期间可以延后到换台时切换。

## 排查配置失败

| 现象 | 优先核对 |
| --- | --- |
| 未配置订阅地址 | 主订阅是否已保存；只填写备用地址不够 |
| 域名解析失败 / 连接超时 | 电视与订阅服务器的网络可达性、DNS、服务器状态 |
| HTTP 401 / 403 | 你是否具备访问资格、令牌是否过期；向内容服务方取得支持 |
| 播放列表无效 | 响应是否为 UTF-8 M3U 原始文本、是否有头部和有效 HTTP(S) 频道 |
| 频道有列表但不能播放 | URL 有效期、设备支持的编码及源站访问条件 |
| 清空后仍在播放旧内容 | 先确认保存的是主订阅并观察界面状态；反馈时说明操作顺序，勿粘贴真实订阅 |

不要用破解、规避鉴权或绕过付费限制的方式处理 401、403、DRM 或地域权限问题。维护者不提供这类操作，也不代查可用源。
